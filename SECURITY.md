# Security Policy

## Reporting a Vulnerability

The project team takes all security vulnerabilities seriously.

To report a security vulnerability, please send an email with a detailed description of the vulnerability and steps to reproduce it. Please do not create a public GitHub issue.

The project team will review the report and respond as appropriate.

## Security Best Practices

We encourage all users to adopt the following security best practices:

*   **Keep dependencies up to date:** Regularly update all dependencies to their latest versions to ensure you have the latest security patches.
*   **Secure your environment:** Ensure that your deployment environment is secure and that you are following security best practices for your cloud provider or infrastructure.
*   **Manage access control:** Use strong passwords and limit access to your production environment to authorized personnel only.

## Security Advisories

Security vulnerabilities will be addressed by the project team. Information on resolved vulnerabilities may be provided through course-specific channels if deemed necessary.
